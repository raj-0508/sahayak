# Sahayak Frontend (Next.js)

This directory contains the frontend source code for **Sahayak**, an AI-powered teaching assistant platform.

## 🚀 Getting Started

### Prerequisites
- Node.js (v20+)
- pnpm (recommended)

### Installation
```bash
pnpm install
```

### Development
```bash
pnpm dev
```
The application will run on [http://localhost:9002](http://localhost:9002).

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router)
- **UI/UX**: Tailwind CSS, Radix UI (Shadcn UI)
- **Icons**: Lucide React
- **Animations**: CSS Transitions / Tailwind Animate
- **Charts**: Recharts
- **State/Data**: React Hooks, Fetch API

## 📂 Structure
- `src/app`: Page routes and layouts.
- `src/components`: UI components (including dashboard features).
- `src/hooks`: Custom React hooks for data and state.
- `src/lib`: API helper functions and shared data types.
